> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `hitl` TypeScript CLI MVP described by the implementation packet.

**Architecture:** A small Node 20 CLI owns workspace creation, internal Git calls, routing, HTML sessions/cards, validation, review, history, and a plain HTTP site. State is local under `.humanintheloop/`; human-facing memory is HTML; machine-readable indexes are JSON.

**Tech Stack:** TypeScript, Node built-ins, Commander, Vitest, Git CLI.
