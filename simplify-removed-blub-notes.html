Simplification and Removal Notes

Running notes for simplifications made while adding template scaffolds.

Design Decisions

Prefer deleting duplicated db-docs helper logic by moving common behavior into one area-docs pipeline. Keep the wrapper only for backward compatibility.

Use a route-slug whitelist from the area-docs registry instead of adding one server branch per template. This keeps route behavior explicit while avoiding repetitive conditionals.

Removed the now-unused area-link write wrapper after changing the scaffold flow to precompute the area-page update before writing generated docs.

Deviations

The database SVG placeholder was not removed even though one simplification review suggested it, because the accepted database-docs plan explicitly required an inline SVG ERD placeholder.

Tradeoffs

Do not refactor unrelated routing, validation, or session internals unless needed for the template feature. The current goal is to remove duplicated scaffold logic, not redesign the HITL system.

The generic module is larger than the original database-only file, but it prevents six copied scaffold lifecycles and keeps new template content declarative.

Open Questions

createDatabaseDocs is now only a compatibility wrapper. Keep it while hitl db-docs is a documented command; remove it only if the public CLI deprecates that alias later.
